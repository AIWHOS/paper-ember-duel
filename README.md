# 纸烬决斗 · Paper Ember Duel

纸片骑士在废弃教室对抗焚卷巨像的 Godot 单人 3D Boss 战试玩原型。

> 发布准备中：仓库已建立，v0.2 工程、模型和 Mac 试玩包正在整理上传，当前页面尚不提供下载。

## 玩法

避开巨像落拳，攻击收招后的拳头。分别击破圆印与三角纸甲后，攻击暴露的核心，完成三个阶段的战斗。

- WASD 跑动，鼠标左键轻击。
- 按住右键超过约 0.25 秒再松开：蓄力纵劈。
- 空格翻滚，Q 弹反落拳，F 镜头归中。
- Esc 暂停，R 结算后重试。

## 制作流程

GPT-6 / Codex 负责看图、拆需求、编写逻辑和调试；Hyper3D Rodin MCP 生成角色与道具；BANG 对完整角色分件；Blender 处理减面、骨骼、权重与武器握持；Godot 完成场景、战斗和画面反馈。BANG 分件不等于自动绑定。

这是 Hyper3D 合作案例的制作展示。
