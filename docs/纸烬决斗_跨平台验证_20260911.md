## Web

使用单线程 WebAssembly + WebGL 2 导出。浏览器实际操作检查覆盖开始游戏、WASD 移动、左键轻击、右键蓄力重击、空格翻滚、Esc 暂停 / 恢复、F8 PNG 下载，并检查 1440×900 与 1280×720 的显示。公开 GitHub Pages 地址再次完成资源加载、开始游戏、移动与翻滚检查。

浏览器不再依赖 Pointer Lock，游戏画面内的鼠标相对移动用于调整镜头。游戏渲染和模型加载未出现运行错误；公开页面记录到站点根 favicon.ico 的 404，不影响试玩。手机触屏未适配，未进行多浏览器 / 多显卡性能基准测试。
